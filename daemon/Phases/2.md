# Backend Phase 2 – Terminal backend

## Goal

Provide real bash PTY sessions through a REST spawn endpoint and a bidirectional WebSocket bridge.

## Depends on

- Phase 0 server foundation
- PTY shapes and framing rules in `../../CONTRACT.md`
- A deliberate authentication and local trust-boundary decision

Because this phase exposes unrestricted shell access, do not ship it while the daemon relies only on CORS or localhost binding as protection.

## Deliverables

- A `portable-pty` session manager
- `POST /api/pty/spawn`
- `WS /ws/pty/:sessionId`
- Input forwarding from WebSocket to PTY stdin
- PTY output forwarding to WebSocket clients
- Resize handling for `cols` and `rows`
- Exit notification containing the process exit code
- Session cleanup on disconnect, timeout, daemon shutdown, and failed startup
- Structured logs using session identifiers without logging terminal contents

## Protocol requirements

Before implementation, make terminal data and control framing unambiguous in `CONTRACT.md`. Define:

- which frames carry raw input and output;
- which frames carry resize and exit messages;
- binary versus text frame rules;
- malformed-frame behavior;
- heartbeat and timeout behavior;
- whether reconnection or session reattachment is supported.

Use `sessionId` consistently in route and JSON-facing terminology.

## Acceptance criteria

- [ ] A valid spawn request starts a PTY in the requested or default working directory.
- [ ] Invalid dimensions and working directories return structured errors.
- [ ] Interactive input and output preserve bytes correctly.
- [ ] Resize messages change PTY dimensions.
- [ ] Process exit produces the documented exit frame.
- [ ] WebSocket disconnect and heartbeat timeout do not leave orphaned shells.
- [ ] Daemon shutdown cleans up all child processes.
- [ ] Concurrent sessions remain isolated.
- [ ] Sensitive terminal content is not written to logs.
- [ ] Formatting, Clippy, and all tests pass.

## Out of scope

- Terminal React or `xterm.js` UI
- Session persistence across daemon restarts
- Remote shell access
- Command filtering or sandboxing
