# App Phase 8.5 - Command Center

## Outcome

A searchable palette over every executable Aqua command — focused-app menu items, window actions,
Spaces actions, and system/daemon lifecycle commands — opened locally inside the WebView.

## Status

Implemented. Trigger is `Ctrl+Shift+/`, a plain WebView key listener in `Desktop.tsx`
(UI-SPEC-14 §2 — no Tauri global-shortcut registration); the listener skips text fields and
Monaco so editor block-comment and form bindings are not hijacked. The registry
(`src/desktop/commandRegistry.ts`) aggregates four sources into `CommandEntry[]` per
UI-SPEC-14 §3/§6: the focused app's `AppMenuGroup[]` from `menus.ts` (its generic Window group
is excluded — those actions come once, from the dedicated window source), `windowStore` actions
(Minimize / Zoom / Move to Space / Close), Spaces actions (Switch to Space N / New Space /
Open Mission Control per UI-SPEC-13 §8), and system commands (`restart_daemon`,
`relaunch_aqua`, `quit_and_stop_daemon` via Tauri invoke, Open Settings, Toggle Spotlight).
The palette (`src/desktop/CommandCenter.tsx`) reuses Spotlight's exact shell and motion token
(`--bg-overlay`, 180ms scale 0.96→1) rather than proposing a new one; rows show label, category
tag, and display-only shortcut hint; keyboard nav is ↑/↓/Enter/Esc with live subsequence fuzzy
filtering over labels + keywords. Error state follows §4: a failed execution leaves the palette
open and renders an inline `--status-danger` note under the failed row. Registry behavior is
covered by `commandRegistry.test.ts`.

## Verification

- `pnpm -C app test` — registry grouping order, enabled states, no-duplicate rule, fuzzy match
- `pnpm -C app build` — typecheck + production bundle
- Manual: open palette with `Ctrl+Shift+/` in dev browser and in the packaged app; execute
  window/space/system commands; confirm failed daemon invoke shows inline error without closing
