# App Phase 3 - Terminal

## Outcome

Terminal hosts unrestricted WSL shells via xterm.js with tabs, resize propagation, and clean exits.

## Backend Prerequisite

Daemon Phase 2 must implement `POST /api/pty/spawn` and `WS /ws/pty/:sessionId` per `CONTRACT.md` (port 61234).

## Deliverables

- xterm.js + fit addons, manifest/Dock entry, PTY spawn with current dims, raw byte bridge, resize debounce, multi-tab isolation, JetBrains Mono, proper disposal.

## Verification

- Test spawn shape, stdin/output/resize/exit/disposal; manual color/Unicode/sudo/copy-paste checks.
