# App Phase 2 - Finder

## Outcome

Finder provides WSL filesystem browsing, CRUD, live updates, and Quick Look previews inside Aqua windows.

## Backend Prerequisite

Daemon Phase 1 must implement `GET /api/fs/list`, `GET /api/fs/read`, `POST /api/fs/op`, `PUT /api/fs/write`, `WS /ws/fs-watch` per `CONTRACT.md`.

## Deliverables

- Finder manifest/Dock entry (`react-icons`), path navigation, list/icon views, CRUD with confirmations, `useFsWatch` with subscribe/unsubscribe/reconnect, multi-window state, previews (image, text/markdown/code, PDF, binary fallback), virtualization over 50 items.

## Verification

- Test list, navigation, CRUD request shapes, watch lifecycle, preview states, keyboard/focus, and large-directory performance.
