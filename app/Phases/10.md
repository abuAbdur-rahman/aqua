# App Phase 10 – Settings + Wallpaper

## Status

Implemented. Settings is a registered Dock/System Menu app with a sidebar shell (Appearance, Wallpaper, Daemon, About). The Wallpaper pane merges frontend-owned built-ins with daemon-served custom uploads; selection applies immediately to the desktop behind every window. Appearance prefs (reduce motion, dock size) persist in localStorage pending a generic daemon prefs API.

## Design

- Follows `../design/UI-SPEC-09-Settings.md`: sidebar selected-state identical to Finder (`--accent-bg` + accent label); wallpaper grid 4-up with accent-ring + checkmark badge selection; custom-tile-only trash badge routed through the shared Confirmation Modal; "+" tile shows a spinner while uploading and a danger "×" for ~2s on failure.
- Upload picker deviates deliberately from this spec's original native-dialog note per `UI-SPEC-09` supersession context: the real Windows dialog comes from a small `pick_image` Tauri command (`rfd`) — OS-integration glue only, no fs-plugin capability surface. A hidden file input stands in for plain `vite dev`.
- Deleting the active custom wallpaper falls back to `aqua` locally in the same beat the daemon does it server-side.
- Reduce motion honors both the in-app toggle and `prefers-reduced-motion`; wired into window open/close, Dock magnification/launch bounce, and the wallpaper cross-fade (100ms opacity). Dock base size is slider-driven (40–56px) with magnify always +16px over base.
- CSP `img-src` now allows `http://localhost:61234` for daemon-served full assets and thumbnails.

## Deliverables

- `lib/api.ts` — wallpaper client (GET/PUT/upload/delete + asset/thumb URL helper)
- `panes/wallpaperStore.ts` — built-ins, load/select/upload/remove with active-delete fallback
- `desktop/Wallpaper.tsx` — desktop layer, 220ms cross-fade between selections
- `panes/SettingsPane.tsx`, `AppearancePane`, `WallpaperPane`, `DaemonPane`, `AboutPane`
- `lib/prefs.ts` — localStorage-backed reduce-motion + dock-size prefs
- `src-tauri` — `pick_image` command (`rfd`), CSP update
- Settings registered in manifest, Dock, WindowFrame (lazy-loaded), and enabled in the System Menu
