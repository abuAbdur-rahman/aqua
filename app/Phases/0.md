# App Phase 0 - Shell and Daemon Handshake

## Outcome

The Windows-native Tauri app opens as a frameless Aqua desktop after the WSL daemon is healthy. The React WebView can call `GET /api/health` and complete a `/ws/echo` round trip on `http://localhost:61234` / `ws://localhost:61234`.

## Ownership

- Implement only `app/` code: Tauri host, React UI, and app tooling.
- Do not create or edit `daemon/` code. The WSL agent owns `daemon/` and endpoint behavior.
- Treat `CONTRACT.md` as the wire-shape source and `DESIGN.md` as the visual-token source.

## Prerequisites

- Daemon Phase 0 exposes `GET /api/health` and `WS /ws/echo` on `127.0.0.1:61234` (see `daemon/Phases/0.md`).
- Windows has Node.js, pnpm, Rust, Tauri prerequisites, WebView2, and WSL2 installed.

## Deliverables

### Scaffold

- Tauri v2 + React + TypeScript already scaffolded in `app/` (`app/src-tauri/` + vite root at `app/`). Keep this layout; if the team later adopts `app/frontend/`, move in one clean commit and update `app/src-tauri/tauri.conf.json` frontendDist.
- Use pnpm (`app/package.json` `packageManager: pnpm@11.6.0`) and commit `app/pnpm-lock.yaml`.

### Styling and icons

- Tailwind CSS v4 via `@tailwindcss/vite` (`tailwindcss` + `@tailwindcss/vite`), imported with `@import "tailwindcss"` and CSS-first `@theme`.
- Do not add legacy Tailwind v3 config without a verified requirement.
- Map every `DESIGN.md` color/chrome value into CSS custom properties and Tailwind `@theme` tokens (`app/src/App.css`).
- `react-icons` is the sole UI icon package. No emoji, handwritten SVG paths, or second icon library.

### Tauri host

- Configure product name `Aqua`, identifier `com.abdul.aqua`, `decorations: false`, `transparent: true`, `visible: false`.
- Allow daemon traffic in CSP: `connect-src http://localhost:61234 ws://localhost:61234`.
- Health-check the daemon before starting the service. Discover the default WSL distro via `wsl -l -v` rather than hardcoding `Ubuntu`.
- If health fails, start the `systemd --user` service via `wsl.exe -d <distro> -- systemctl --user start aqua-daemon.service` (idempotent) and poll `http://localhost:61234/api/health` about every 200 ms for up to 5 s (25×200ms). Service is prebuilt via `daemon/deploy/install.sh`; no `cargo run` at launch. `resolve_daemon_dir`/`AQUA_DAEMON_DIR` are diagnostics-only, not used in the hot path.
- Show a visible startup failure state if WSL, service start, or health polling fails. Leave the daemon running when Aqua exits — quit is `app.exit(0)` only; explicit stop is `POST /api/system/shutdown` then `systemctl --user stop` via the separate `stop_daemon` command.

### React shell

- Build `Desktop`, `MenuBar`, and `Dock` shells using Tailwind utilities backed by project tokens.
- Use the dark-only cool-neutral palette and subtle deep-teal wallpaper from `DESIGN.md`.
- Reserve menu bar and Dock space so desktop content never renders beneath them.
- Expose daemon connection state as connecting / connected / failed; status must include text, not color alone.
- Keep `/ws/echo` as a typed development probe with cleanup on unmount and no `console.log` in production code.
- Add visible keyboard focus, accessible names for icon-only buttons, and reduced-motion handling.

## Not In Scope

- Generic app windows, drag, resize, snapping, or minimization.
- Finder, Terminal, Activity Monitor, Editor, Spotlight, Spaces, or persistence.
- Backend implementation or changes to backend-owned payloads.

## Verification

- `pnpm -C app tsc --noEmit` and `pnpm -C app build` pass.
- `cargo check` in `app/src-tauri` passes after `pnpm -C app tauri dev` compiles once (first compile installs WebView2/Rust deps).
- Tauri starts from `app/` and shows frameless window with no native title bar.
- Existing healthy daemon service is reused; a second `systemctl --user start` is a no-op if already active.
- Unavailable daemon produces the designed failure state after timeout.
- `/api/health` and `/ws/echo` work from the WebView on port `61234` without CSP errors.

## Exit Gate

Phase 1 starts only after the shell, daemon lifecycle, CSP, Tailwind v4 tokens, and WebView round trip all pass.
