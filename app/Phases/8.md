# App Phase 8 - Persistence and Desktop Polish

Layout load/restore via `GET/PUT /api/state/layout` (daemon Phase 5, port 61234), debounced writes, viewport clamping, focused-app menus, Dock magnification (48→64px, 120ms), tray actions, and final a11y/bundle audits.

## Status

Implemented and verified. Load-on-boot and debounced (~1s) writes run via `src/lib/useLayoutPersistence.ts`; restored windows are clamped into the MenuBar/Dock-reserved region (`src/lib/layout.ts`). Tauri host ships tray Show/Quit plus graceful daemon shutdown (`src-tauri/src/lib.rs`). Dock magnification is live (`DOCK_MAGNIFY_DELTA`, reduced-motion aware). Per-app menu bars are real handlers for every registered app. Bundle audit: Monaco, Terminal, Settings, and Gallery are lazy chunks. A11y audit: focus-visible outlines on interactive elements, labels on icon-only controls, images with alt text, no div-as-button patterns.
