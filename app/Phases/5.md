# App Phase 5 - Editor

Monaco-based editor lazy-loaded only on first open (daemon Phase 1 fs endpoints, port 61234). Multi-tab dirty tracking, `PUT /api/fs/write` saves, language detection, `utf8`/truncated handling, JetBrains Mono theme, and bundle-split verification.

- `DESIGN.md` + `UI-SPEC-00` + `UI-SPEC-05-Editor.md` (tab strip 28px accent dot, Monaco themed to DESIGN.md, 24px status bar, states Loading/Empty/Populated/Error-read/Error-write, truncated/base64 handling).
